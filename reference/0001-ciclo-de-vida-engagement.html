Contrato de toda skill codebase-*

  • Roda uma ferramenta. Uma skill, um job.
  • Declara orçamento de tokens (input/output) no frontmatter.
  • Escreve o output bruto em disco, nunca no contexto do pai.
  • Devolve resumo estruturado ≤1k tokens.
  • Devolve status OK / DEGRADED / FAILED + motivo; respeita timeout do orquestrador.

Contrato do Report Agent

  • Consome só os resumos — nunca o bruto.
  • Todo status não-OK vira bloco SECTION UNAVAILABLE visível (ferramenta + motivo).
  • Aplica a si mesmo o checklist de validação do tier (trilha de auditoria T1).
